01

基本問題 · リストの作成

アイテムリストを作ろう

約5分

ゲームの持ち物として、「剣」「盾」「薬草」をまとめたリストを作ろう。

作るプログラムの条件

  1. items という名前のリストを作る
  2. リストには 「剣」「盾」「薬草」をこの順番で入れる
  3. print(items) でリスト全体を表示する
出力例
['剣', '盾', '薬草']
できたら試そう

「薬草」を自分の好きなアイテム名に変えて実行してみよう。

ヒント①　リストの書き方を思い出そう

リストは [ ] を使い、データをカンマ , で区切るよ。文字列は " " で囲もう。

ヒント②　コードを確認しよう
items = ["剣", "盾", "薬草"]
print(items)

表示される [ ] や ' も、Pythonがリストを表示するときの普通の形だよ。

基本問題 · append / len

アイテムを追加しよう

約10分

アイテムリストに「ポーション」を追加して、持ち物が何個あるか数えよう。

作るプログラムの条件

  1. 問題①と同じ items のリストを作る
  2. append() を使い、「ポーション」を追加する
  3. 追加後のリスト全体を表示する
  4. len() を使って、アイテムの個数を表示する
出力例
['剣', '盾', '薬草', 'ポーション']
アイテムの数：4個
できたら試そう

さらに「地図」を追加してみよう。アイテムの数は何個になるかな？

スタート用コードを見る（必要な人だけ）

ここから始めてもOK。続きを自分で考えてみよう！

items = ["剣", "盾", "薬草"]

# ここに追加する処理を書こう
ヒント①　追加する命令は？

items.append("ポーション") を使うと、リストの最後に「ポーション」が追加されるよ。

ヒント②　何個あるか調べるには？

len(items) がアイテムの個数を表すよ。表示するときは、print(f"アイテムの数：{len(items)}個") と書ける。

04

演習問題 · リスト × random × if

ランダム宝箱を作ろう！

約15分

宝箱を開けると、リストの中からランダムに1つアイテムが出てくるプログラムを作ろう。

作るプログラムの条件

  1. リスト items に 「剣」「盾」「薬草」「宝石」を入れる
  2. random.choice(items) でアイテムを1つ選ぶ
  3. 「宝箱から○○が出た！」と表示する
  4. 「宝石」が出たときだけ「レアアイテム！」、それ以外なら「アイテムをゲット！」と表示する
出力例（一例）
宝箱から宝石が出た！
レアアイテム！
※出てくるアイテムは毎回変わるよ。宝石以外なら「アイテムをゲット！」と表示されればOK！
できたら試そう

何度も実行してみよう。「宝石」以外が出たときにも、正しく表示されるかな？

スタート用コードを見る（必要な人だけ）

このコードを動かしてから、条件分岐を追加しよう。

import random

items = ["剣", "盾", "薬草", "宝石"]
item = random.choice(items)
print(f"宝箱から{item}が出た！")

# ここに条件分岐を書こう
ヒント①　ランダムで選ぶには？

最初に import random を書こう。item = random.choice(items) とすると、リストからランダムに選んだアイテムを item に入れられるよ。

ヒント②　宝石だったらどうする？
if item == "宝石":
    print("レアアイテム！")
else:
    print("アイテムをゲット！")

この条件分岐を、ランダムに選んで表示したあとの行に追加してみよう。

A

CHALLENGE ①

3連宝箱にしよう

問題④の宝箱を改造して、1回の実行で3つのアイテムを手に入れよう。

条件

  1. for と range() で3回繰り返す
  2. 毎回 random.choice(items) でアイテムを選ぶ
  3. 「1回目：剣」のように、何回目かとアイテムを表示する
出力例（一例）
1回目：剣
2回目：薬草
3回目：宝石
※どのアイテムが何回出るかはランダムだよ。
できたら試そう

宝石が出たときだけ「レア！」も表示できるかな？

ヒント①　何を3回繰り返す？

for i in range(3): の内側に、random.choice(items) と表示の処理を書こう。

ヒント②　何回目か表示するには？

i は0から始まるよ。print(f"{i + 1}回目：{item}") を使おう。

CHALLENGE ②

オリジナルキャラクターを作ろう

2つのリストを使って、名前と職業をランダムに組み合わせたキャラクターを作ろう。

条件

  1. 名前のリスト names を作る（例：ルナ、カイ、ソラ）
  2. 職業のリスト jobs を作る（例：剣士、魔法使い、忍者）
  3. それぞれのリストから1つずつランダムに選ぶ
  4. 選んだ名前と職業を合わせて表示する
出力例（一例）
名前：ルナ
職業：忍者
※出てくる組み合わせは毎回変わるよ。
できたら試そう

名前や職業を好きなものに変えて、自分だけのキャラクター生成プログラムにしよう。

ヒント①　リストを2つ作ろう
names = ["ルナ", "カイ", "ソラ"]
jobs = ["剣士", "魔法使い", "忍者"]

自分で別の名前・職業を考えてもOK！

ヒント②　2回ランダムに選ぼう

name = random.choice(names) と job = random.choice(jobs) のように、それぞれ選ぼう。最後に print(f"名前：{name}") などで表示しよう。
