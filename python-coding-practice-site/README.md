# Python自習課題｜リストを使いこなそう！

前回の「繰り返し」課題サイトと同一のCSS・画面構成・操作を引き継いだWeb教材です。

## 出題内容
- 基本問題①：リストを作る（items）
- 基本問題②：添字を使いデータを取り出す
- 基本問題③：append()・len()で追加と件数表示
- 演習問題④：random.choice()とifでランダム宝箱
- チャレンジA：forで3連宝箱
- チャレンジB：2つのリストからキャラクターを生成

## 教材の仕様
- 50分の自習用。基本3問達成で今日の最低目標達成
- 出力例、できたら試そう、段階的なヒント、必要な問題にはスタート用コード
- 「動かせた！」のチェック状態をブラウザのlocalStorageに記録
- HTML/CSS/JavaScriptのみ、外部ライブラリ不要
- Pythonの実行はTechNexus上で行う
- 授業資料URLは未指定のため記載せず、TechNexusへのリンクのみ配置
- 教材内に課題の日付や「第○回」は記載していません

## GitHub Pagesで公開するには
フォルダ内の index.html / styles.css / app.js / favicon.svg を新しいGitHubリポジトリにアップロードし、Settings → Pages → main / root を選びます。既存リポジトリを上書きしないでください。

※ユーザーが共有した前回教材ZIPをデザイン・UIの原本として使用。
